# Hotel Booking Cancellation Prediction

## Project Overview
This project uses Machine Learning to predict whether a hotel booking will be canceled or not. It analyzes booking-related features to identify cancellation patterns and support better hotel booking management.

## Objectives
- Predict hotel booking cancellations.
- Analyze customer booking patterns.
- Identify important factors affecting cancellations.
- Compare different Machine Learning classification models.

## Workflow
1. Data Loading and Exploration
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Outlier Analysis
5. Feature Encoding
6. Train-Test Split
7. Model Building and Training
8. Model Evaluation
9. Booking Cancellation Prediction

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

## Best Model Results
**Random Forest Classifier**

- Accuracy: 82.46%
- ROC-AUC: 0.864

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Conclusion
The project demonstrates how Machine Learning can be used to predict hotel booking cancellations. Random Forest achieved 82.46% accuracy, while XGBoost achieved a higher ROC-AUC score of 0.881.

This project helped me understand data preprocessing, exploratory data analysis, classification algorithms, model comparison, and evaluation techniques.
